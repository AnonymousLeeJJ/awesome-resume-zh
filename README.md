## 🤔 为什么做这个库？

做一份好看的简历，不该要先注册账号、看广告、最后发现导出 PDF 要收费。

这里的模板是**纯 HTML 文件**：下载 → 用记事本改成你的内容 → 浏览器打开 → Ctrl+P 存为 PDF。没有账号、没有水印、没有付费墙，永远免费（CC0 公有领域协议）。

## 🚀 三步上手

1. **选模板**：打开 [在线挑选页](https://anonymousleejj.github.io/awesome-resume-zh/)，点「下载模板」
2. **改内容**：用任意文本编辑器打开 HTML，替换示例文字
3. **导出 PDF**：浏览器打开 → `Ctrl+P` → 目标选「另存为 PDF」→ 边距选「无」→ 勾选「背景图形」
