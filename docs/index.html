❓ 常见问题

怎么把模板改成我自己的内容？

下载 HTML 文件后，用任意文本编辑器（记事本、VS Code 都可以）打开，把里面的示例文字替换成你的信息，保存后用浏览器打开即可看到效果。

怎么导出 PDF？

用浏览器打开模板，按 Ctrl+P（Mac 是 Cmd+P），目标打印机选「另存为 PDF」，边距选「无」或「最小」，勾选「背景图形」，保存即可。
